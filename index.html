Action-Conditioned Video World Model

Completed

PSIML 2026  ·  5 days  ·  one shared A100 40GB  ·  pair project with Mihajlo Stevanović

A pretrained video diffusion model can continue a scene. Can it be taught to obey? Given a few real frames of a robot arm and a commanded gripper displacement, predict the future — and have the arm actually move the way it was told.

Built on minWM (Wan2.1-T2V-1.3B). Upstream conditions on camera pose; conditioning on robot action is the gap this fills. The 1.3B backbone is pretrained — the work here is a rank-16 LoRA plus an action encoder, fine-tuned on BAIR robot pushing at 64×64.

What I built

  • LoRA + action-encoder fine-tuning on BAIR, 8000 steps
  • The evaluation harness, including two controls that changed how every number is reported: a learned null-action embedding and a divergence noise floor
  • A DMD-distilled vs teacher-forcing comparison, to answer whether flow-matching fine-tuning undoes the distillation
  • A scheduled-sampling ablation, and goal-conditioned action search (6×6 grid, one batched forward pass)
  • The diagnosis of the free-rollout failure described below

Result

Direction accuracy, relative 99.6% (255/256) does right end up right of left?
Direction accuracy, absolute 84.8% did each command move its own way?
Value of the action signal +5.29 dB PSNR with the real action minus PSNR with a null one
PSNR 18.56 dB against a 22.74 dB VAE ceiling at this resolution — 82% of it

Held-out 256-scene test split, best checkpoint, teacher-forced context. FID/FVD sample counts are far below convention and are valid only as relative comparisons between our own checkpoints.

What went wrong, and what it turned out to mean

A Monte Carlo free rollout — where each block's context is the previous block's own output — first read as control degrades with depth. That was wrong. A targeted diagnostic, issuing opposite commands from the same self-generated context, showed relative direction accuracy holding at 98–100% through all three self-generated blocks. What degrades is the arm's absolute position and the image quality, not its obedience: the mechanism is exposure bias, a named failure mode with known mitigations. Scheduled sampling roughly halved the quality decay for a real cost of 1.5 dB single-step fidelity.

Classifier-free guidance was tried and did not help: relative direction accuracy is already saturated at w=1, so it amplifies nothing while costing fidelity and a second forward pass. Reported as a measured negative result.
